# To-Do-List
# 📝 To-Do List App (Python + Tkinter)

A simple and user-friendly To-Do List desktop application built using Python and Tkinter.  
This app allows users to **add**, **delete**, and **mark tasks as completed**, with all tasks saved locally to a file.

---

## 🚀 Features

- ✅ Add new tasks
- 🗑️ Delete selected tasks
- ✔️ Mark tasks as completed
- 💾 Tasks are saved to `tasks.txt` automatically
- 🔁 Loads saved tasks when reopened

---

## 🖥️ Tech Stack

- **Language**: Python 3.x
- **GUI**: Tkinter (Standard Python Library)

---

## 📦 Requirements

- Python 3.x (https://www.python.org/downloads/)
- No external libraries needed (only `tkinter`)

---

## ▶️ How to Run

1. **Clone or Download** this repository.
2. Open a terminal or command prompt in the project directory.
3. Run the app using:

   ```bash
   python todo_app_clean.py
   ```
## 📁 File Structure

todo-list-app/
│
├── todo_app_clean.py   # Main Python GUI app
├── tasks.txt           # Auto-generated file to store tasks
└── README.md           # Project documentation
⚠️ tasks.txt is created automatically when you run the app and add tasks.
